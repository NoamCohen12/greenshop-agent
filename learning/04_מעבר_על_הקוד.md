## 4.1 `src/state.py`

```python
class GreenShopState(TypedDict):
    user_message: str

    is_input_valid: bool
    block_reason: Optional[str]
    route: Optional[Literal["knowledge_question", "customer_specific"]]

    retrieved_context: Optional[str]
    tool_result: Optional[dict]
    draft_answer: Optional[str]

    is_output_safe: bool
    final_answer: Optional[str]
    guardrail_feedback: Optional[str]
    regeneration_attempts: int
```

**מבנה:** השדות מקובצים לפי הצומת שממלא אותם.

**`Optional[str]`** = "או מחרוזת או `None`". בתחילת הריצה רוב השדות `None` — עוד לא הגענו לצומת שממלא אותם.

**`Literal[...]`** מגביל לערכים מותרים בלבד. אם מישהו יכתוב `route = "customer"` (חסר `_specific`) — העורך יסמן שגיאה לפני ההרצה.

**שאלה אפשרית:** "למה `regeneration_attempts` הוא `int` ולא `Optional[int]`?"
**תשובה:** כי הוא תמיד מאותחל ל-0 ב-`server.py`. אין מצב שהוא לא קיים.

## 4.2 `src/model_provider.py`

```python
def get_chat_model():
    provider = os.environ.get("MODEL_PROVIDER", "ollama").lower()

    if provider == "ollama":
        from langchain_ollama import ChatOllama
        return ChatOllama(model=os.environ.get("OLLAMA_MODEL", "llama3.2"), temperature=0)

    if provider == "openai":
        from langchain_openai import ChatOpenAI
        api_key = os.environ.get("OPENAI_API_KEY")
        if not api_key:
            raise ValueError("OPENAI_API_KEY חסר ב-.env כאשר MODEL_PROVIDER=openai")
        return ChatOpenAI(model=..., api_key=api_key, temperature=0)

    raise ValueError(f"MODEL_PROVIDER לא מוכר: '{provider}'")
```

**שלוש נקודות להסביר:**

**1. `temperature=0`** — פרמטר שקובע כמה המודל "יצירתי":
- `0` = דטרמיניסטי. אותו קלט → אותו פלט (כמעט תמיד)
- `0.9` = מגוון ויצירתי

בחרנו 0 כי בשירות לקוחות רוצים **עקביות**. שני לקוחות עם אותה שאלה צריכים לקבל אותה תשובה. יצירתיות כאן היא באג, לא פיצ'ר.

**2. ייבוא בתוך הפונקציה** — `from langchain_ollama import ...` נמצא **בתוך** ה-`if`, לא בראש הקובץ. כך אם עובדים עם OpenAI בלבד, הספרייה של Ollama לא נטענת כלל.

**3. `raise ValueError` בסוף** — אם מישהו כותב `MODEL_PROVIDER=gpt` בטעות, הוא מקבל שגיאה ברורה מיד, ולא התנהגות מוזרה בהמשך.

## 4.3 `src/nodes/input_guardrail_router.py` — צומת 1

```python
class RouterDecision(BaseModel):
    is_valid: bool = Field(description="האם ההודעה תקינה ורלוונטית לשירות לקוחות של חנות")
    block_reason: str = Field(description="אם לא תקינה - הסבר קצר למה. אחרת מחרוזת ריקה")
    route: str = Field(description="'knowledge_question' או 'customer_specific'...")


def input_guardrail_router_node(state: GreenShopState) -> dict:
    model = get_chat_model()
    router_model = model.with_structured_output(RouterDecision)

    decision = router_model.invoke([
        {"role": "system", "content": ROUTER_SYSTEM_PROMPT},
        {"role": "user", "content": state["user_message"]},
    ])

    return {
        "is_input_valid": decision.is_valid,
        "block_reason": decision.block_reason or None,
        "route": decision.route or None,
    }
```

**`decision.block_reason or None`** — טריק Python: מחרוזת ריקה היא "falsy", ולכן `"" or None` מחזיר `None`. זה ממיר מחרוזת ריקה ל-`None`, שמתאים ל-`Optional[str]` ב-State.

**שני התפקידים בצומת אחד** — שאלה שעשויה להישאל: "למה לא הפרדת ל-2 צמתים?"
**תשובה:** שני התפקידים דורשים את אותה הבנה של ההודעה. הפרדה הייתה מחייבת שתי קריאות למודל — כפול עלות וזמן, בלי רווח. הפלט המובנה מאפשר לקבל את שתי ההחלטות בקריאה אחת.

### פונקציית ההחלטה

```python
def route_after_input_guardrail(state: GreenShopState) -> str:
    if not state["is_input_valid"]:
        return "blocked"
    if state["route"] == "customer_specific":
        return "customer_specific"
    return "knowledge_question"
```

**סדר הבדיקות חשוב:** קודם בודקים תקינות. הודעה שנפסלה לא ממשיכה לניתוב — גם אם המודל מילא `route` כלשהו.

## 4.4 `src/rag/vector_store.py` + `src/nodes/retrieval.py` — צומת 2

### בניית המסד

```python
def build_vector_store() -> Chroma:
    documents = []
    for file_path in glob.glob(os.path.join(KNOWLEDGE_BASE_DIR, "*.txt")):
        with open(file_path, encoding="utf-8") as file:
            documents.append(Document(
                page_content=file.read(),
                metadata={"source": os.path.basename(file_path)},
            ))

    splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50, ...)
    chunks = splitter.split_documents(documents)

    return Chroma.from_documents(
        documents=chunks,
        embedding=get_embedding_model(),
        collection_name=COLLECTION_NAME,
        persist_directory=CHROMA_PERSIST_DIR,
    )
```

**`persist_directory`** — בלעדיו המסד יושב בזיכרון ונעלם בסיום התהליך. איתו הוא נשמר לדיסק.

**שתי פונקציות נפרדות:**
- `build_vector_store()` — יוצרת מאפס. רצה פעם אחת (ingestion)
- `load_vector_store()` — טוענת קיים. רצה בכל שאלה

### הצומת

```python
def retrieval_node(state: GreenShopState) -> dict:
    vector_store = load_vector_store()
    results = vector_store.similarity_search(state["user_message"], k=3)
    context_text = "\n\n---\n\n".join(doc.page_content for doc in results)
    return {"retrieved_context": context_text}
```

**`"\n\n---\n\n"`** — מפריד ויזואלי בין הקטעים, כדי שהמודל יבין שאלה מקורות נפרדים ולא טקסט רציף אחד.

## 4.5 `src/tools/n8n_tool.py` + `src/nodes/tool_execution.py` — צומת 3

### הכלי

```python
@tool
def call_n8n_webhook(request_type: str, order_id: str, details: str = "") -> dict:
    """
    שולח בקשה למערכת n8n לביצוע פעולה על הזמנת לקוח.

    יש להשתמש בכלי הזה כאשר הלקוח מבקש מידע או פעולה שקשורים
    להזמנה ספציפית שלו, כגון בדיקת סטטוס משלוח או בקשת החזר כספי.

    Args:
        request_type: "order_status" או "refund_request"
        order_id: מספר ההזמנה של הלקוח.
        details: פרטים נוספים רלוונטיים לבקשה.
    """
    webhook_url = os.environ.get("N8N_WEBHOOK_URL")
    if not webhook_url:
        return {"success": False, "error": "N8N_WEBHOOK_URL לא מוגדר ב-.env"}

    try:
        response = requests.post(webhook_url, json={...}, timeout=10)
        response.raise_for_status()
        return response.json()
    except requests.RequestException as error:
        return {"success": False, "error": str(error)}
```

**ה-docstring הוא לא תיעוד — הוא חלק מהתוכנית.** זה הטקסט שהמודל קורא כדי להחליט מתי ואיך להפעיל את הכלי. ניסוח מעורפל → שימוש שגוי.

**`timeout=10`** — בלעדיו, n8n תקוע היה תוקע את כל הבקשה ללא הגבלה.

**`try/except` שמחזיר dict במקום לזרוק** — אם n8n נופל, הסוכן מקבל `{"success": False, "error": ...}` ויכול לומר ללקוח "יש תקלה זמנית". בלי זה, חריגה הייתה מפילה את כל הגרף.

### הצומת

```python
def tool_execution_node(state: GreenShopState) -> dict:
    agent = create_agent(
        model=get_chat_model(),
        tools=[call_n8n_webhook],
        system_prompt=TOOL_EXECUTION_SYSTEM_PROMPT,
    )

    response = agent.invoke({"messages": [HumanMessage(content=state["user_message"])]})

    tool_result = None
    for message in response["messages"]:
        if getattr(message, "name", None) == "call_n8n_webhook":
            tool_result = message.content
            break

    return {"tool_result": tool_result}
```

**כאן נמצאת האוטונומיה.** לא אנחנו מחלצים את מספר ההזמנה — המודל עושה זאת. הוא קורא "ההזמנה 55555 הגיעה פגומה", מבין שמדובר בבקשת החזר, ובונה את הקריאה:
```
call_n8n_webhook(request_type="refund_request", order_id="55555", details="המוצר הגיע פגום")
```

**הלולאה בסוף:** תשובת הסוכן היא רשימת הודעות (שאלה → קריאה לכלי → תוצאה → תשובה). אנחנו מחפשים בה את ה-`ToolMessage` — ההודעה שמכילה את מה ש-n8n החזיר.

**`getattr(message, "name", None)`** — לא לכל סוג הודעה יש שדה `name`. `getattr` עם ברירת מחדל מונע קריסה.

## 4.6 `src/nodes/generation.py` — צומת 4

```python
def generation_node(state: GreenShopState) -> dict:
    model = get_chat_model()

    context_parts = []
    if state.get("retrieved_context"):
        context_parts.append(f"מידע מבסיס הידע:\n{state['retrieved_context']}")
    if state.get("tool_result"):
        context_parts.append(f"תוצאת בדיקה במערכות החברה:\n{state['tool_result']}")
    if state.get("guardrail_feedback"):
        context_parts.append(f"הטיוטה הקודמת נפסלה... יש לתקן: {state['guardrail_feedback']}")

    context_text = "\n\n".join(context_parts) if context_parts else "לא נמצא מידע רלוונטי."

    response = model.invoke([
        SystemMessage(content=GENERATION_SYSTEM_PROMPT),
        HumanMessage(content=f"שאלת הלקוח: {state['user_message']}\n\n{context_text}"),
    ])

    return {"draft_answer": response.content}
```

**למה שלושה `if` נפרדים ולא `if/elif`:** כי ייתכן שיהיה גם וגם. בפועל המסלולים נפרדים, אבל המבנה תומך בהרחבה עתידית שבה שאלה תדרוש גם RAG וגם n8n.

**השדה `guardrail_feedback`** הוא מה שהופך את הלולאה למועילה — בלעדיו הסוכן היה מייצר בדיוק את אותה תשובה שוב.

**`response.content`** — המודל מחזיר אובייקט `AIMessage`, לא מחרוזת. `.content` מחלץ את הטקסט.

## 4.7 `src/nodes/output_guardrail.py` — צומת 5

```python
class OutputCheck(BaseModel):
    is_safe: bool
    issue: str


def output_guardrail_node(state: GreenShopState) -> dict:
    checker_model = get_chat_model().with_structured_output(OutputCheck)

    source_parts = []
    if state.get("retrieved_context"):
        source_parts.append(f"מידע מבסיס הידע:\n{state['retrieved_context']}")
    if state.get("tool_result"):
        source_parts.append(f"נתונים שהוחזרו ממערכות החברה:\n{state['tool_result']}")
    source_info = "\n\n".join(source_parts) if source_parts else "אין מידע נוסף"

    check = checker_model.invoke([...])

    if check.is_safe:
        return {"is_output_safe": True, "final_answer": state["draft_answer"]}

    attempts = state.get("regeneration_attempts", 0) + 1
    if attempts > MAX_REGENERATION_ATTEMPTS:
        return {"is_output_safe": False, "final_answer": FALLBACK_ANSWER, "regeneration_attempts": attempts}

    return {"is_output_safe": False, "guardrail_feedback": check.issue, "regeneration_attempts": attempts}
```

**שלושה מסלולי יציאה:**
1. אושר → `final_answer` נקבע, הגרף מסתיים
2. נפסל, נותרו ניסיונות → `guardrail_feedback` נקבע, `final_answer` נשאר `None`
3. נפסל, נגמרו ניסיונות → `final_answer` = fallback

**הבחנה חשובה:** במקרה 2, `final_answer` **נשאר `None`** — וזה בדיוק מה שה-Conditional Edge בודק כדי להחליט אם לחזור.

## 4.8 `src/graph.py` — חיבור הכל

```python
def build_graph():
    graph = StateGraph(GreenShopState)

    graph.add_node("input_guardrail_router", input_guardrail_router_node)
    graph.add_node("blocked_input", blocked_input_node)
    graph.add_node("retrieval", retrieval_node)
    graph.add_node("tool_execution", tool_execution_node)
    graph.add_node("generation", generation_node)
    graph.add_node("output_guardrail", output_guardrail_node)

    graph.add_edge(START, "input_guardrail_router")

    graph.add_conditional_edges(
        "input_guardrail_router",
        route_after_input_guardrail,
        {
            "blocked": "blocked_input",
            "knowledge_question": "retrieval",
            "customer_specific": "tool_execution",
        },
    )

    graph.add_edge("retrieval", "generation")
    graph.add_edge("tool_execution", "generation")
    graph.add_edge("generation", "output_guardrail")

    graph.add_conditional_edges(
        "output_guardrail",
        route_after_output_guardrail,
        {"retry_generation": "generation", "end": END},
    )

    graph.add_edge("blocked_input", END)

    return graph.compile()
```

**`compile()`** — מוודא שהגרף תקין (אין צמתים מנותקים, כל היעדים קיימים) ומחזיר אובייקט להרצה.

### פונקציית ההחלטה השנייה

```python
def route_after_output_guardrail(state: GreenShopState) -> str:
    if state["is_output_safe"] or state["final_answer"] is not None:
        return "end"
    return "retry_generation"
```

**שני התנאים ב-`or` מכסים את שלושת המקרים:**
- `is_output_safe=True` → תשובה אושרה → סיום
- `is_output_safe=False` אבל `final_answer` קיים → נגמרו הניסיונות, זה ה-fallback → סיום
- `is_output_safe=False` ו-`final_answer is None` → יש עוד ניסיונות → חזרה

## 4.9 `src/server.py` + `src/startup.py`

```python
@app.route("/chat", methods=["POST"])
def chat():
    body = request.get_json(silent=True) or {}
    user_message = body.get("message", "").strip()

    if not user_message:
        return jsonify({"error": "יש לשלוח שדה 'message' לא ריק"}), 400

    initial_state = {
        "user_message": user_message,
        "is_input_valid": True,
        "block_reason": None,
        ...
        "regeneration_attempts": 0,
    }

    result_state = greenshop_graph.invoke(initial_state)
    return jsonify({"answer": result_state["final_answer"]})
```

**`silent=True`** — אם ה-JSON פגום, מחזיר `None` במקום לזרוק חריגה. כך התגובה היא 400 מסודר ולא 500.

**כל השדות מאותחלים במפורש** — גם אלה שיהיו `None`. זה הופך את ה-State לצפוי: כל צומת יכול לסמוך על כך שהמפתח קיים.
